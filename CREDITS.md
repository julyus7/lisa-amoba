# Credits and source provenance

These games were developed for Gyula's Apple Lisa project in September–October
2026 with AI coding assistance. The Hungarian game logic, standalone identities,
custom icons, packaging fixes and validation were developed for this project.

The native LOS application shell and supporting units derive from
[Alex's LOS Minesweeper](https://github.com/alexthecat123/los_minesweeper),
local upstream revision `df8f65012b381341e4a4f70604505300214614fb`.
The released game floppies were assembled using its tool-floppy filesystem
as a template. Supporting units retain original Minesweeper identifiers and
some unused original functionality.

The development also consulted
[Steven Troughton-Smith's LisaOSToolKitSample](https://github.com/steventroughtonsmith/LisaOSToolKitSample),
local revision `145555a825761d7e061b6b57047e715ab5ac890c`.
Emulation used [LisaEm](https://github.com/rayarachelian/lisaem).
